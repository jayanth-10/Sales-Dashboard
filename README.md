# 📊 Sales Dashboard (Power BI)

This interactive **Sales Dashboard** project was created using **Power BI** to analyze and visualize a company's sales data. 
The goal is to provide clear, actionable insights into sales performance, trends, and product profitability across different regions and time periods.

## 🚀 Key Features:
- **Dynamic KPIs**: Total Revenue, Quantity Sold, Profit Margin
- **Time Series Analysis**: Monthly and yearly sales trends
- **Category & Sub-Category Breakdown**: Top-performing products and segments
- **Geographical Insights**: Regional sales distribution with map visuals
- **Customer Insights**: Sales by customer type and behavior

## 🛠️ Tools Used:
- Power BI – for visualization and dashboard creation  
- DAX – for custom metrics and calculations  
- Microsoft Excel – data source  
- (Optional) Python – for data cleaning or mock data generation  

## 📈 Business Value:
This dashboard empowers stakeholders to:
- Identify sales trends and seasonal patterns  
- Detect underperforming regions or products  
- Make data-driven decisions to boost revenue
